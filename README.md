# 01 — Deep Learning From Scratch

This section is the foundation of my deep learning journey.

The goal is to understand what happens **inside a neural network** rather than immediately relying on high-level deep learning frameworks.

I am implementing the fundamental concepts using **Python and NumPy**, building components manually and gradually increasing the complexity of the models.

## 🎯 Goals

* Understand how neural networks work internally
* Implement neural networks using NumPy
* Understand forward propagation
* Understand backpropagation
* Learn how gradients are calculated
* Implement activation functions
* Understand loss functions
* Implement gradient descent
* Understand weights and biases
* Learn how training actually works
* Build models without TensorFlow or PyTorch
